# Phase 3 CP5 C1–D1–E1–F1–G1 Closure Design

## Authority and scope

This design closes the CP5 C0/D0/E/F/G integrated handoff from baseline
`10e23abb0706e21506945f687d0de84008d45a9f`. It preserves the accepted
CP5-A/B foundations and proceeds sequentially through C1, D1, E1, F1, and
G1, followed by one definitive disposable-worktree regression and one
external review. CP5-H/I, DrawingML, PPTX, template reconstruction, private
source access, and private rendering remain prohibited.

## Closure sequence

`P0 → C1 → D1 → E1 → F1 → G1 → cross-gate acceptance → full regression → external review`.

Each gate starts with defect-detecting tests, validates its own contracts and
execution evidence, commits a recoverable checkpoint, and continues without
an intermediate external approval.

## C1: canonical output authority and style proof

CP1 `FigureOutputManifest` v3 is instantiated, schema-validated, and hash
bound for every applicable output. The Scientific SVG envelope is supplemental
validation evidence. Static FigureCritic consumes a typed review bundle and
proves FOM/envelope/spec/plan/primary-artifact identity closure, canonical
SVG closure, provenance validity, route-specialist validity, actual resolved
style-value application, and runtime-only layout eligibility.

Resolved style is an immutable bundle. Each SVG attribute application records
the target, category, token or fallback identity, source value, and serialized
SVG value; critic verification parses the canonical SVG rather than trusting
the trace. Material-semantic scientific colors remain unresolved.

## D1: generalized structured directors

Five distinct directors remain: Fishbone, mechanism, experiment, fabrication,
and comparison. Their layouts derive from typed input collections and stable
relationships rather than representative fixture IDs. Fishbone hierarchy,
causal-state graphs, variable experiment collections, mixed known/UNKNOWN
fabrication conditions, and allowed comparison side counts are explicitly
validated. All style values flow through C1’s resolved bundle.

## E1: evidence-bound outputs

Scientific plots use immutable canonical numeric input and data-derived
geometry, labels, units, and hashes. Image matrices use valid committed
synthetic panels with per-panel source/hash/provenance/order/scale lineage.
Photo and literature remain `BLOCKED_SOURCE` absent permitted inputs; concepts
remain `non_evidence` and never provide scientific claim support.

## F1: truthful render and review boundaries

A `RendererAdapter` supports a real host probe and a deterministic positive
test adapter. Host unavailability remains `blocked_environment`; it does not
erase the tested positive path. Render manifests bind the SVG and PNG hashes,
adapter identity/version, parameters, dimensions, and measured critic facts.
`ReviewAction` uses recursive immutable data and defensive reads. Context stays
transient and contains visual binding references only.

## G1: measured structural calibration

A01–A18 records retain only measurements supportable by committed sanitized
evidence, VSP003, and D1/E1 outputs. They distinguish supported, provisional,
insufficient evidence, environment blocks, and qualitative-review blocks.
Representative and stress benchmark fixtures carry invariants and evaluation
results. Fishbone calibration preserves each supported field’s evidence and
status. Separate calibration montages are structurally and visually distinct.

## Cross-cutting truth constraints

- CP1 FigureOutputManifest stays canonical; no alternative FOM is created.
- Canonical SVG is visual IR, not Ledger/evidence provenance.
- No empirical or literature evidence is invented; synthetic fixtures are
  explicitly synthetic test material.
- Private alias/source/render counters remain `0/0/0`.
- Final acceptance requires frozen tested/current candidate hash equality,
  disposable-worktree regression, current repository and staged privacy scans,
  and exact scope audit.
