# Phase 3 CP5 C0–D0–E–F–G Integrated Sprint Design

## Authority and scope

This design is the durable authority for one continuous, internally gated implementation sprint. It starts from `42150711432933d02087b301bd3f6907022270fa` and proceeds only through C0, D0, E, F, and G. CP5-H/I, DrawingML, PPTX, template reconstruction, and all private-source access are out of scope.

## Gate sequence

`P0 → C0 → D0 → E → F → G → one external review`.

Each gate uses RED→GREEN tests, schema closure, execution-derived QA, a recoverable commit, and focused validation. Only after G is frozen will a single durable full disposable-worktree regression execute.

## C0: approval trust boundary

CP1 `FigureOutputManifest` remains canonical. CP5-C supplies an optional SVG validation envelope and a deterministic Static FigureCritic report. Persisted approval JSON is evidence only; Layout receives a non-forgeable runtime `ApprovedFigureHandle` produced by executed critic validation or complete re-verification.

## D0: specialist structured directors

Fishbone, mechanism, experiment, fabrication, and fair-comparison directors own their individual visual semantics. They share only low-level SVG primitives. Every representative traverses CP5-A validation, CP1 output manifest, CP5-C envelope/critic, and runtime approval. VSP003 tokens are selected through a category-resolution map based on the actual profile fields, with explicit fallback/unresolved provenance.

## E: evidence-bound visual directors

Plot, photo annotation, literature figure, image matrix, and concept illustration remain separate routes. Synthetic plot/matrix fixtures may be approved only as explicitly synthetic test evidence. Missing permitted real photo/literature sources yield typed blocked states. Concepts remain non-evidence and cannot support a scientific claim.

## F: review dimensions

Renderer probing, render critic, image-capable qualitative review, and human review are independent status dimensions. Missing renderer or authorized provider yields a truthful blocker without invalidating legal SVG/static approval. CurrentSlideContext is transient; immutable ReviewAction cannot mutate Ledger truth.

## G: sanitized-domain calibration

G consumes only committed CP2/CP3 artifacts, A01–A18 authority, and C0–F outputs. It produces structural/provisional calibration and benchmark artifacts while keeping render and qualitative acceptance separate. No private aliases, raw profiles, exemplar renders, or PPTX are inputs.

## Cross-cutting constraints

- Private alias/source/render counters remain `0/0/0`.
- No thesis empirical data, literature recreation, or AI evidence is fabricated.
- Canonical SVG is visual authoring IR, not scientific provenance.
- Material-semantic colors remain unresolved unless later content-aware authority permits them.
- Durable validation records pre/post candidate hashes, command, logs, exit status, and completion marker locally only.
